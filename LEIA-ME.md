# Portfolios PWA — publicar no GitHub Pages
1. Crie um repositório e suba TODO o conteúdo da pasta `portfolios-pwa/` na raiz (inclui `.nojekyll`).
2. Settings → Pages → Branch `main` / pasta `/ (root)`.
3. No celular abra `https://<usuario>.github.io/<repo>/` → iPhone: Safari › Compartilhar › Adicionar à Tela de Início; Android: Chrome › Instalar app.
4. A cada atualização: gerar nova pasta (build_pwa.py) e substituir os arquivos. O app mostra "Nova atualização disponível" e atualiza com 1 toque.
Atenção: repositório público expõe os dados. Para privado use Cloudflare Pages/Netlify com senha.
